# SwipeGPT: Step-by-Step Execution Plan

This document outlines the precise, sequential steps required to build the SwipeGPT Chrome Extension according to the PRD and TRD. 

## Phase 0: Project Setup & Architecture
**Goal:** Establish the foundation and ensure Chrome can load the extension[cite: 1].

1.  **Initialize Directory:** Create the root `swipegpt/` folder and the required subdirectories: `content/`, `popup/`, `background/`, `storage/`, and `assets/`[cite: 1].
2.  **Create Manifest:** Write the `manifest.json` file using Manifest V3[cite: 1]. Ensure permissions for `storage`, `activeTab`, and `scripting` are included, along with host permissions for OpenAI domains[cite: 1].
3.  **Create Placeholders:** Create empty files for all necessary scripts (`content.js`, `cardParser.js`, `swipeEngine.js`, `popup.js`, `service-worker.js`, etc.)[cite: 1].
4.  **Load Extension:** Go to `chrome://extensions`, enable "Developer Mode", and load the unpacked `swipegpt/` directory to verify the baseline setup works[cite: 1].

## Phase 1: Standalone Swipe Engine (Demo Mode)
**Goal:** Perfect the core interaction without worrying about live ChatGPT DOM scraping[cite: 1].

1.  **Create Demo Environment:** Create `demo/index.html` and a corresponding script to act as a sandbox[cite: 1].
2.  **Mock Data:** Generate hardcoded JSON arrays representing mock ChatGPT outputs (e.g., 5 project ideas, pros/cons)[cite: 1].
3.  **Build the UI Shell:** Write `styles.css` to render the stacked card interface with a dark, modern, glassmorphism vibe (blur, gradients, drop shadows)[cite: 2]. Include the title, content snippet, and pagination (e.g., "1 / 5")[cite: 2].
4.  **Implement Physics (`swipeEngine.js`):** 
    *   Add event listeners for `pointerdown`, `pointermove`, and `pointerup`[cite: 1].
    *   Apply `transform: translate3d(x, y, 0) rotate(z)` for smooth hardware-accelerated movement[cite: 1].
    *   Map rotation to the horizontal drag distance (e.g., `rotate = x * 0.05deg`)[cite: 1].
5.  **Implement Gestures:** Trigger actions based on drag threshold (~40% of screen width) or velocity[cite: 1].
    *   Swipe Left = Reject/Dismiss[cite: 2]
    *   Swipe Right = Save/Like[cite: 2]
    *   Swipe Up = Expand/Explore[cite: 2]
    *   Swipe Down = Save for later[cite: 2]
6.  **Add Spring-back:** If a drag doesn't meet the threshold, animate the card smoothly back to the center[cite: 2].

## Phase 2: ChatGPT DOM Integration
**Goal:** Inject the UI activation button safely into the ChatGPT interface[cite: 1].

1.  **Setup MutationObserver (`content.js`):** Monitor the DOM for completed AI responses[cite: 1]. Do not rely on fragile CSS classes; use structural selectors[cite: 1].
2.  **Inject Activation Button:** Append a lightweight `[ Swipe this answer ]` button beneath the active response block once generation stops[cite: 1, 2].
3.  **Overlay Container:** When the button is clicked, create a fixed container with a high `z-index` to host the SwipeGPT card interface over the ChatGPT view[cite: 1]. 

## Phase 3: Parsing Logic (`cardParser.js`)
**Goal:** Convert raw ChatGPT HTML/Markdown into structured card data[cite: 1].

1.  **DOM Extraction:** Write regex and traversal logic to target lists (`<ol>`, `<ul>`), headings followed by paragraphs (`<h3>` + `<p>`), and bolded line items[cite: 1].
2.  **Data Structuring:** Map extracted items to the Card Object Schema (`id`, `title`, `content`, `type`, `sourceMessageId`, `createdAt`, `status`)[cite: 1].
3.  **Failsafe Logic:** If the parser cannot identify separable items (low confidence), return `null` and display a graceful error/info message in the UI instead of rendering broken cards[cite: 1, 2].

## Phase 4: State Management & Popup UI
**Goal:** Persist user actions and build the extension's dashboard[cite: 1, 2].

1.  **Storage Wrapper (`storage/storage.js`):** Implement functions to get, set, and delete cards using `chrome.storage.local`[cite: 1].
2.  **Connect Swipes to Storage:** When a user swipes right (Save), write the current card object to `chrome.storage.local`[cite: 1, 2]. Implement an "Undo previous swipe" utility[cite: 2].
3.  **Build Popup (`popup.html` & `popup.js`):**
    *   Create the dashboard displaying stats: Cards viewed, Cards saved, Cards dismissed[cite: 2].
    *   Add settings toggles for animations, density, themes, and shortcuts[cite: 2].
    *   Include a deep link button to open the "Saved Cards" view[cite: 2].

## Phase 5: Final Polish & Review
**Goal:** Ensure a premium native feel and resolve edge cases[cite: 2].

1.  **Refine Transitions:** Smooth out opacity and scale transitions for background cards[cite: 2]. Ensure velocity-based exit trajectories look natural[cite: 2].
2.  **Verify Non-Destruction:** Ensure that opening and closing the SwipeGPT overlay does not modify or break the original ChatGPT DOM or interfere with normal scrolling and typing[cite: 1, 2].
3.  **End-to-End Testing:** Open ChatGPT, ask for "5 project ideas", click the activation button, swipe through the stack, verify saves in the popup, and ensure smooth operation[cite: 1, 2].
